# T021 evidence - deterministic placement rules

## Result

Implemented data-only C04 placement records for forest, meadow, and rocky
habitats. Positions are owned by a logical cell in `[0, 256)` metres, records
use independent C02 channels and stable IDs, and actual terrain readiness,
height, and slope are checked before a record is returned. Missing or
unapproved asset IDs are rejected; no placeholder asset is selected.
