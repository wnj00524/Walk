## Implemented evidence

`ChunkTerrain` generates height samples from logical integer chunk coordinates,
creates visual meshes and `HeightMapShape3D` collision on the main thread,
keeps a 3x3 active ring, and rejects stale worker results by generation epoch.
The direct probe waits for asynchronous chunks to become ready and queries the
same logical centre after each simulated origin move.
