## Implementation

Implemented the guarded Meshy API v2 client in `tools/meshy_client.py`.
Dry-run is the default; execution requires the environment key, an approved
named budget, and `--execute`. Receipts preserve request hashes and task IDs.
Submission timeouts become `SUBMISSION_UNKNOWN` without a retry. Polling is
bounded, and GLB downloads require the documented Meshy asset host, a size
limit, and an optional SHA-256 match before atomic promotion.
