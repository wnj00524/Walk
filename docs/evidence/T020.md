# T020 evidence - configurable landform recipe

## Result

Implemented one checked-in temperate landform recipe and a typed validator;
the main walker now loads it before configuring the accepted terrain service.
The recipe uses the accepted `ChunkTerrain` heightmap path: 256 m chunks, a
3-by-3 support ring, 32 samples per side, 0.0035 cycles/m noise frequency,
and a 48 m vertical range starting at -12 m. No second height model was added.
