# T010 - verification record

## Change and user-visible result

Added a bounded large-distance coordinate investigation using the pinned
Voxel Tools terrain configuration. Logical positions remain representable at
zero, ±100 km, and ±1000 km, including negative cells and repeated crossings
at 99,999 m / 100,001 m. The native `Vector3` loses 0.03125 m at the tested
1,000,000.03125 m points. The candidate handoff—moving the visual walker to
the origin without a native generator offset—changes the sampled height by
6.926433 m, so it does not preserve terrain identity.

This is a completed feasibility investigation, not backend acceptance. Native
collision was not ready in the headless run, consistent with T009's known
limitation; the graphical process initialized on the RTX 2060 but no retained
screenshot was captured in this run.
