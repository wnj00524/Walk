# T018 evidence

## Implementation

Added an offline GLB validator/report writer and a labelled Godot inspection
fixture. The Python tool measures the file hash, byte size, glTF 2.0 metadata,
node/mesh/material/primitive counts, indexed triangle count, and accessor
bounds. It rejects missing, malformed, oversized, meshless, and unusable
inputs. Scale and vertical pivot are recorded as a wrapper transform; source
bytes are not rewritten, and no Blender or `.blend` dependency exists.
