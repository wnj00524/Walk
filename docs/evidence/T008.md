Installed the exact Voxel Tools 1.7 GDExtension archive recorded by T001 under
`game/addons/voxel/`. The project can load the native extension in a headless
Godot runtime. The probe constructs the required generator, viewer, terrain,
and level-of-detail terrain classes and records the API exposed by the binary.
