## Outcome

A genuine smooth terrain surface streams around the moving viewer using the selected native facilities.

## Read set

Read the root rules/orientation/recent log, then the metadata read set and actual files being changed. Read dependency evidence when its result fixes a version or interface. Do not read every task.

## Allowed changes

Only the metadata paths, plus this task's evidence report, its relevant feature walkthrough, CODE_GUIDE.md, its PLAN.md row and one appended DLOG.md row. Directory scopes are not permission for unlimited changes. Do not change rules/contracts unless explicitly listed.

## Steps

1. Use only API names established by T008. Programmatically configure a simple native 2D-height or graph-based smooth generator and viewer.
2. Enable collision and simple neutral material. Wire the existing walker through a spawn-wait state until collision is ready.
3. Record configured view range, actual diagnostic access and generation settings. Treat this as a technical probe, not the final biome.

## Acceptance

- Walk across multiple real backend block boundaries, turn back and verify continuous collision and persistent landform identity.
- Record movement distance, actual resident data/mesh counts where supported and any unavailable metrics. Capture an actual graphical run.
- Run `python tools/project.py validate` and the existing helper tests. Explain the changed code in ordinary language and update its feature walkthrough.

## Non-goals

No per-voxel GDScript production loops, foliage, water, custom mesher or claim of beauty.

## Stop conditions

Native graph authoring cannot be scripted, required ready-state information is unavailable, or scope needs more than one narrow prototype. Also apply AGENTS.md: stop after two failed focused repairs, for unapproved spend, unavailable required evidence, or when the coordinator must split the scope.
