## Outcome

Ground, rocks and vegetation belong to one restrained visual palette under fixed daylight.

## Read set

Read the root rules/orientation/recent log, then the metadata read set and actual files being changed. Read dependency evidence when its result fixes a version or interface. Do not read every task.

## Allowed changes

Only the metadata paths, plus this task's evidence report, its relevant feature walkthrough, CODE_GUIDE.md, its PLAN.md row and one appended DLOG.md row. Directory scopes are not permission for unlimited changes. Do not change rules/contracts unless explicitly listed.

## Steps

1. Configure only the material/environment operations verified for the selected backend.
2. Expose named safe controls for texture scale, light intensity and fog where actually supported; validate ranges.
3. Compare fixed views without hiding terrain defects with heavy fog or bloom.

## Acceptance

- Invalid preset values fail; fixed views show appropriate material scale and consistent ground contact.
- Existing terrain/placement suites still pass.
- Run `python tools/project.py validate` and the existing helper tests. Explain the changed code in ordinary language and update its feature walkthrough.
- After the suite exists, run `python tools/check_game.py --suite visual_preset` and affected regression suites. This command is introduced by T004; T003 uses the direct Godot script command while bootstrapping.

## Non-goals

No custom lighting engine, day/night/weather system or shader megaframework.

## Stop conditions

The desired material blend needs unverified backend features. Also apply AGENTS.md: stop after two failed focused repairs, for unapproved spend, unavailable required evidence, or when the coordinator must split the scope.
