## Outcome

A cell has reproducible, irregularly clustered approved objects that obey slope and surface rules.

## Read set

Read the root rules/orientation/recent log, then the metadata read set and actual files being changed. Read dependency evidence when its result fixes a version or interface. Do not read every task.

## Allowed changes

Only the metadata paths, plus this task's evidence report, its relevant feature walkthrough, CODE_GUIDE.md, its PLAN.md row and one appended DLOG.md row. Directory scopes are not permission for unlimited changes. Do not change rules/contracts unless explicitly listed.

## Steps

1. Implement C04 records with canonical half-open ownership, channel-separated choices and a fixed stable order.
2. Use actual approved terrain queries and classify only forest/meadow/rocky variants in the initial palette.
3. Keep this task data-only. Document editable density/scale/slope limits and reject missing catalogue IDs.

## Acceptance

- Same seed and reversed cell-load order give identical records; neighbouring cells do not duplicate boundary objects.
- Invalid terrain readiness produces deferred placement, not floating objects at height zero.
- Run `python tools/project.py validate` and the existing helper tests. Explain the changed code in ordinary language and update its feature walkthrough.
- After the suite exists, run `python tools/check_game.py --suite placement` and affected regression suites. This command is introduced by T004; T003 uses the direct Godot script command while bootstrapping.

## Non-goals

No scene nodes, MultiMesh renderer, global climate or new asset generation.

## Stop conditions

A terrain surface query or asset contract is unresolved. Also apply AGENTS.md: stop after two failed focused repairs, for unapproved spend, unavailable required evidence, or when the coordinator must split the scope.
