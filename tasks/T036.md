## Outcome

A specific offline build is approved as the first nature-walking experience, with honest limits and no extra game mechanics.

## Read set

Read the root rules/orientation/recent log, then the metadata read set and actual files being changed. Read dependency evidence when its result fixes a version or interface. Do not read every task.

## Allowed changes

Only the metadata paths, plus this task's evidence report, its relevant feature walkthrough, CODE_GUIDE.md, its PLAN.md row and one appended DLOG.md row. Directory scopes are not permission for unlimited changes. Do not change rules/contracts unless explicitly listed.

## Steps

1. Run a real 20-30 minute free walk plus the fixed checks on more than one seed, including a pre-recorded unselected seed.
2. Review landform continuity, vegetation, water, comfort, sound, resume and known performance limits together.
3. Record owner acceptance, unresolved non-blocking issues and how to run the build. Defer new biomes/weather/rivers to separately designed work.

## Acceptance

- Owner accepts the actual exported build; technical gates and documentation are complete.
- No hidden live API dependency, required manual editor step, fake infinite horizon or placeholder accepted as final art.
- Run `python tools/project.py validate` and the existing helper tests. Explain the changed code in ordinary language and update its feature walkthrough.

## Non-goals

No new mechanics or claim that all future distances/hardware are proven.

## Stop conditions

Any required gate, visual/audio decision or retained evidence is missing. Also apply AGENTS.md: stop after two failed focused repairs, for unapproved spend, unavailable required evidence, or when the coordinator must split the scope.
