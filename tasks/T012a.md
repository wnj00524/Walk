## Outcome

A GDScript chunked-heightmap terrain service that satisfies the frozen C03
adapter contract, survives three simulated visual-origin recenterings with
≤ 0.01 m height discontinuity at the recentering boundary, and provides
collision shapes for the nearest chunks. The `backend_gate` check in
`docs/toolchain.lock.json` is set to true **only if all listed acceptance
criteria pass**. T013 and later terrain-dependent tasks remain WAITING until a
reviewer accepts this spike.

## Background

T010 found that Voxel Tools `VoxelGeneratorNoise` changes the sampled height by
6.926433 m after a visual-origin handoff because the native generator reads
world-space `Vector3` inputs. T012 rejected that backend. The coordinator
investigation (DLOG 2026-09-17, D17) evaluated three alternatives and
recommended a pure-GDScript chunked heightmap because:

- Noise inputs are computed from 64-bit logical integer coordinates and small
  local floats; a visual-origin recentering never changes what `FastNoiseLite`
  sees.
- On recentering, existing chunk meshes are shifted by a small delta. No
  re-streaming, no stutter.
- The C03 frozen adapter boundary maps directly onto this implementation.
- No new binary dependency is introduced; `FastNoiseLite` is a Godot built-in.

The Voxel Tools GDExtension bundle in `game/addons/voxel/` is kept as a
documented probe reference. Do not remove it.

## Steps

1. Read the C03 contract methods in `docs/CONTRACTS.md` (configure,
   update_viewer, get_ground_state, query_surface, get_diagnostics, shutdown).
   Read the existing `terrain_service.gd` probe for the pattern to follow.
   Read `world_position.gd` for the C01 logical coordinate layout.

2. Create `game/src/terrain/chunk_terrain.gd` — a `Node3D` subclass that:
   - On `configure(world_identity, recipe)` validates the C02 identity dict,
     stores `world_seed` (int), `chunk_size_m` (default 256.0),
     `view_chunks` (default 3, giving a 3×3 ring of loaded chunks),
     and returns `{"status": "READY"}` or `{"status": "ERROR", "error": …}`.
   - Maintains a dictionary of active `MeshInstance3D` chunks keyed by
     `(chunk_cx, chunk_cz)` logical chunk coordinates.
   - On `update_viewer(logical_position: WorldPosition)` determines which
     chunk coordinates should be in the ring; creates any missing chunks on
     `WorkerThreadPool` (the mesh-generation callback) and frees any
     out-of-range chunks. Updates internal viewer position.
   - Each chunk mesh is built with `SurfaceTool` or `ArrayMesh` at a
     configurable vertex density (default 32 vertices per side, i.e. 1,024
     vertices per chunk). Heights are computed by `FastNoiseLite` using
     `(logical_chunk_x * chunk_size_m + local_x_m)` — **always logical-space
     inputs, never renderer-space inputs**.
   - Collision: generates a `CollisionShape3D` with a `HeightMapShape3D` for
     the 3×3 nearest chunks only; uses `call_deferred` to apply it on the
     main thread after the background job completes.
   - `get_ground_state(logical_position)` returns `"READY"` if the chunk
     containing that position has a completed collision shape, `"PENDING"` if
     the background job is running, `"OUTSIDE_TESTED_SUPPORT"` if the
     position is beyond the configured ring, or `"ERROR"` if unconfigured.
   - `query_surface(logical_position)` returns the state and, when READY,
     samples `FastNoiseLite` with the same logical inputs to return
     `{"status": "READY", "height_m": …, "normal": …}`. PENDING never
     returns a height.
   - `get_diagnostics()` returns active epoch, last logical viewer position,
     loaded chunk count, and pending job count.
   - `shutdown()` cancels pending jobs, frees all chunk nodes, resets state.
     Safe to call once. Callable from any state.
   - Uses a generation epoch: `configure` increments the epoch; a background
     job discards its result if the epoch has changed when it completes.

3. Create `game/tests/probes/chunk_terrain_probe.gd` — a headless probe that:
   - Calls `configure` with a C02 valid identity dict and default recipe.
   - Calls `update_viewer` at logical position (0, 0) and waits up to 300
     frames for the nearest chunk to reach `get_ground_state = "READY"`.
   - Records the `query_surface` height at the exact centre of chunk (0, 0).
   - Simulates a visual-origin recentering by calling `update_viewer` at a
     position 256 m away, recording the viewer logical position.
   - After a second ready signal, re-queries the same logical coordinate and
     asserts `|height_after - height_before| ≤ 0.01 m`.
   - Repeats for a total of three recenterings.
   - Asserts `get_ground_state` at a coordinate 10 × chunk_size beyond the
     ring returns `"OUTSIDE_TESTED_SUPPORT"`.
   - Exits 0 on all assertions pass; exits 1 on any failure, printing the
     offending value.

4. Create `game/tests/probes/chunk_terrain_probe.tscn` — a minimal scene
   containing only the probe script node. No walker, no sky, no other terrain.
   Keep it as a text `.tscn` file.

5. Register a `"chunk_terrain"` suite in `game/tests/run_tests.gd` that runs
   the probe.

6. Update `docs/features/terrain-api.md` to describe the new
   `ChunkTerrain` service: what it does, why it exists, the coordinate
   strategy, what changed from the Voxel Tools probe, and what is not yet
   proven (foliage, water, GPU performance at full quality, Windows export).

7. Update `docs/CODE_GUIDE.md` with a plain-English entry for
   `game/src/terrain/chunk_terrain.gd`.

8. Run all checks (see Acceptance). If the headless probe exits 1, diagnose
   the failure and fix it once. If it fails a second time on a different root
   cause, stop and record a BLOCKED state with the smallest reproducible
   failure.

## Acceptance

All of the following must be met and recorded in `docs/evidence/T012a.md`:

- `python tools/project.py validate` exits 0.
- `python -m unittest discover -s tools -p "test_*.py"` exits 0 (30+ tests).
- `python tools/check_game.py --suite smoke` exits 0.
- `python tools/check_game.py --suite chunk_terrain` exits 0 with ≥ 3 checks
  passed (the three recentering identity checks).
- `godot --headless --path game --script res://tests/probes/chunk_terrain_probe.gd`
  exits 0 with all assertions passed and a recorded `|Δheight| ≤ 0.01 m` for
  each of the three simulated recenterings.
- `get_ground_state` returns `"OUTSIDE_TESTED_SUPPORT"` for a coordinate
  beyond the loaded ring (asserted in the probe).
- A graphical scene run on the RTX 2060 (the owner's Windows machine) renders
  terrain visible, with no seams at chunk boundaries and collision active.
- Frame time measured ≥ 55 fps during a short graphical walk at the default
  view distance. If the frame budget is not met after one tuning attempt, stop
  and report the measured value — do not silently shrink the world.

On full acceptance: set `checks.backend_gate: true` in
`docs/toolchain.lock.json` and move T012a to REVIEW. Do not set the gate true
if the graphical or performance check is NOT RUN.
