## Outcome

An asset choice is repeatable for the same world, location and channel, regardless of load order.

## Read set

Read the root rules/orientation/recent log, then the metadata read set and actual files being changed. Read dependency evidence when its result fixes a version or interface. Do not read every task.

## Allowed changes

Only the metadata paths, plus this task's evidence report, its relevant feature walkthrough, CODE_GUIDE.md, its PLAN.md row and one appended DLOG.md row. Directory scopes are not permission for unlimited changes. Do not change rules/contracts unless explicitly listed.

## Steps

1. Implement the exact C02 ASCII payload and SHA-256 interpretation using the pinned engine API.
2. Validate canonical seed/channel/slot inputs. Do not use a mutable global random stream or the built-in string hash.
3. Consume the independent fixture rather than generate expected results from the new implementation.

## Acceptance

- Match every expected first_u32 value and unit interval in fixtures/seed_vectors.json.
- Repeated, shuffled and reversed input orders give the same mapped results; invalid identifiers fail explicitly.
- Run `python tools/project.py validate` and the existing helper tests. Explain the changed code in ordinary language and update its feature walkthrough.
- After the suite exists, run `python tools/check_game.py --suite deterministic` and affected regression suites. This command is introduced by T004; T003 uses the direct Godot script command while bootstrapping.

## Non-goals

No terrain noise algorithm, platform-wide mesh determinism promise or vegetation renderer.

## Stop conditions

A fixture fails after two focused fixes; never rewrite the fixture to fit the code. Also apply AGENTS.md: stop after two failed focused repairs, for unapproved spend, unavailable required evidence, or when the coordinator must split the scope.
