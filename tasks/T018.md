## Outcome

A local candidate model can be imported and reviewed without Blender or manually changing import settings.

## Read set

Read the root rules/orientation/recent log, then the metadata read set and actual files being changed. Read dependency evidence when its result fixes a version or interface. Do not read every task.

## Allowed changes

Only the metadata paths, plus this task's evidence report, its relevant feature walkthrough, CODE_GUIDE.md, its PLAN.md row and one appended DLOG.md row. Directory scopes are not permission for unlimited changes. Do not change rules/contracts unless explicitly listed.

## Steps

1. Validate local input, run the pinned importer and inspect mesh/material/bounds data using verified Godot APIs.
2. Apply a documented wrapper transform for scale/pivot; create simple collision/detail-level settings only through a reproducible command or import script.
3. Produce a technical JSON report and fixed close/mid/far review views. Split the task before READY if implementation exceeds the file/line budget.

## Acceptance

- Reject malformed/empty/missing-dependent/oversized inputs; report actual counts and dimensions rather than assumed values.
- Show an explicit test fixture imports without any .blend file or Blender executable. Real asset approval remains T019.
- Run `python tools/project.py validate` and the existing helper tests. Explain the changed code in ordinary language and update its feature walkthrough.

## Non-goals

No mesh sculpting, hand-retopology, silent material replacement or catalogue approval.

## Stop conditions

Required correction cannot be scripted within the approved toolchain. Also apply AGENTS.md: stop after two failed focused repairs, for unapproved spend, unavailable required evidence, or when the coordinator must split the scope.
