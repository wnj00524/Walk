## Outcome

## Read set

Read the root rules/orientation/recent log, then the metadata read set and actual files being changed. Read dependency evidence when its result fixes a version or interface. Do not read every task.

## Steps

1. Use one documented simple shader appropriate for the approved asset data. Do not assume branch weights exist in a generic generated mesh.
2. Anchor motion near the base using a tested local-height/mask convention; leave static rock/trunk collision unchanged.
3. Expose bounded intensity/speed settings, default to restrained values, and review near/far motion.

## Acceptance

- A graphical clip shows grounded bases and no extreme whole-tree bending or distant shimmer.
- Wind disabled restores the unchanged static appearance; resident batch limits are unaffected.
- Run `python tools/project.py validate` and the existing helper tests. Explain the changed code in ordinary language and update its feature walkthrough.
